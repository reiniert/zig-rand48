The `rand48` module provides an idiomatic Zig version of the [POSIX rand48 family of functions](https://pubs.opengroup.org/onlinepubs/9799919799/functions/drand48.html), implemented to provide the same functionality but with Zig-native types and more comprehensible names. As prescribed, it uses a Linear Congruential Generator (LCG) based on 48-bit arithmetic internally.

For the documentation of this module, see the project's auto-generated Github Pages [here](https://reiniert.github.io/zig-rand48/).

This is a toy project, for educational purposes only.
